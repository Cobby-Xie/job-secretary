# 求职秘书 0.1.2

首个可供完整体验的 Windows x64 测试版。

## 亮点

- 省份—城市联动的企业与官方招聘入口发现流程。
- 可编辑简历、照片上传、四种模板和 DOCX/PDF 导出。
- JD 证据匹配、定制简历副本、质量检查分与经历缺口。
- 岗位推荐、每日三道面试题和回答分析。
- 求职记录、提醒、本地备份和 Windows 加密密钥存储。
- 支持主流云端 AI API、本地 Ollama 和外部 AI 编程助手工作流。

## 已知限制

- 安装包尚未代码签名，Windows 可能显示“未知发布者”。
- 动态招聘网站不一定能由通用适配器读取，必须以企业官网页面为准。
- AI 功能需要用户自己的 API Key；普通聊天会员通常不能直接作为 API 调用额度。
- 桌面版当前只支持 Windows x64。
